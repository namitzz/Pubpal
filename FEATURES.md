# PubPal Features

## 🎉 Event Management

### Create Events
- Set event name, location, date and time
- Auto-generated unique 6-character join codes
- Share code or link with friends
- No registration required

### Event Dashboard
- View all event details
- See list of participating teams
- Real-time leaderboard
- Manage pub stops
- Access group chat

## 🗺️ Pub Discovery

### Find Nearby Pubs
- Uses device geolocation
- Searches via OpenStreetMap/Overpass API
- Interactive Leaflet map display
- Shows pub names and addresses
- Within 2km radius by default

### Manual Stop Addition
- Add any pub/bar by name
- Set custom rules for each stop
- Reorder stops as needed
- Delete stops if plans change

## 👥 Team Features

### Team Creation
- Create teams within events
- Unique team join codes
- Add unlimited team members
- Team chat (coming soon)

### Team Scorecard
- Track scores for each stop
- Real-time stroke counting
- See team total
- Add notes per stop
- Compete on leaderboard

## ⛳ Pub Golf Rules

### Custom Rules Per Stop
- Set drink requirements
- Add stroke penalties
- Create fun dares or challenges
- Examples:
  - "Order a pint, +1 for spillage"
  - "Finish in one go or +2 strokes"
  - "Do a dance move, -1 stroke"

### Scoring System
- Golf-style scoring (lower is better)
- Track strokes per stop
- Calculate team totals
- Real-time leaderboard updates
- See completed stops count

## 💡 Tips for Best Experience

1. **Pre-plan Your Route**
   - Use the discover feature before the event
   - Check opening hours
   - Consider walking distances

2. **Set Clear Rules**
   - Define rules before starting
   - Make them fun but achievable
   - Consider penalties and bonuses

3. **Keep it Safe**
   - Drink responsibly
   - Plan transportation
   - Stay together as group
   - Have a designated meetup point

4. **Engage Everyone**
   - Use team chat to coordinate
   - Share photos (coming soon)
   - Encourage friendly competition
   - Celebrate milestones

5. **Have Fun!**
   - Don't take scores too seriously
   - Enjoy the journey
   - Make memories
   - Use the chat to banter 🍻
